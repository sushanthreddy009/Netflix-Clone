<h1 align="center"> 	:film_projector: Netflix - Clone  </h1>

This website aimed to recreate the functionalities of the Netflix streaming site using Typescript, Next.js, with the main goal of testing my knowledge in CRUD operations. I fetched data from an external API, TMDB, displayed the results, and manipulated them as needed. The project was built using Next.js, TypeScript, Bootstrap, and MaterialUI for the front-end. It is hosted on Vercel, and the source code is available on my GitHub.
